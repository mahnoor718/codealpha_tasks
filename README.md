# Task 1: Network Sniffer

## CodeAlpha Cyber Security Internship

### Project Overview
This project is a basic Network Sniffer developed as part of the CodeAlpha Cyber Security Internship. It demonstrates how network packets can be captured and inspected to understand network communication.

### Objectives
- Understand basic network traffic monitoring.
- Learn how network packets are captured and analyzed.
- Explore information contained in network packets.
- Develop practical knowledge of network security fundamentals.

### Technologies Used
- **Programming Language:** Python
- **Concepts:** Network Packet Capture and Traffic Analysis

### Features
- Captures network packets.
- Displays packet information for basic analysis.
- Helps understand how data travels across a network.
- Provides hands-on experience with network monitoring.

### Requirements
- Python 3
- Appropriate packet-capture permissions
- Any required packet-capture library used by the implementation

### How to Run
1. Install Python 3 on your system.
2. Open the project folder in VS Code.
3. Install any dependencies required by the code.
4. Run the Python script from the terminal:

```bash
python network_sniffer.py
```

**Note:** Replace `network_sniffer.py` with your actual Python filename if it is different.

### Learning Outcomes
- Gained practical exposure to network packet capture.
- Improved understanding of network communication.
- Learned basic cybersecurity monitoring concepts.

### Ethical Use
Use this tool only on networks and devices you own or have explicit permission to monitor. Do not capture or inspect other people's traffic without authorization.
